# photos

Every picture on the site is a file in this folder. The pages read them
straight from here — nothing in the code needs to change when you swap one.

| file           | where it shows up                                        |
|----------------|----------------------------------------------------------|
| `hero.jpg`     | the big picture behind the heading on the home page      |
| `services.jpg` | the band behind the heading on the services page         |
| `wash.jpg`     | the band behind the heading on the car wash page        |
| `about.jpg`    | the band behind the heading on the about page           |
| `logo.png`     | the round logo in the header, on every page              |
| `work-1.jpg`   | our work, tile **01** — inside the bay                   |
| `work-2.jpg`   | our work, tile **02** — foam and shine                   |
| `work-3.jpg`   | our work, tile **03** — tyre service                     |
| `work-4.jpg`   | our work, tile **04** — keys ready                       |
| `work-5.jpg`   | our work, tile **05** — interior care                    |
| `work-6.jpg`   | our work, tile **06** — the workshop on Gagnheiði        |

The numbers match the ones printed on the tiles themselves, so you can tell
which file goes where just by looking at the page.

## How to replace one

1. Open this folder on GitHub and click the file you want to change.
2. Press **⋯ → Replace file** and upload your picture.
3. Keep the **same file name**, including the extension. Commit.

An empty file simply does not load, and the site draws its own background
instead — so a tile you have not filled yet still looks finished.

## What to upload

**hero.jpg** — landscape, roughly 3:2 (for example 2400 × 1600). The heading
sits over the left half, so leave that side calm and keep the subject right.

**services.jpg**, **wash.jpg**, **about.jpg** — short, wide bands, roughly
3:1 (for example 2400 × 800). The heading sits on the left, and the bottom
edge fades into the page colour.

**logo.png** — square, at least 200 × 200. It is masked into a circle, so keep
the important part away from the corners. A transparent background works.

**work-1 … work-6** — the tiles are different shapes, and the picture is
cropped to fill, so keep the subject near the middle. Tiles 1 and 6 are wide,
4 is tall, the rest are close to square. Around 1600 px on the long side is
plenty.

## Size

Keep each file under about **500 KB**, and the logo under 100 KB. Saving a
JPEG at around 80% quality gets almost any photo there with no visible
difference. Large files do not break anything, but every visitor downloads
them before the page finishes drawing, which is felt most on a phone.
