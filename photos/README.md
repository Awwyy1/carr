# photos

Pictures that live in the repository. The site reads them straight from this
folder — nothing in the code needs to change when you swap one.

| file           | where it shows up                                        |
|----------------|----------------------------------------------------------|
| `hero.jpg`     | the big picture behind the heading on the home page      |
| `services.jpg` | the band behind the heading on the services page         |
| `logo.png`     | the round logo in the header, on every page              |

## How to replace one

1. Open this folder on GitHub and click the file you want to change.
2. Press the pencil (or **⋯ → Replace file**) and upload your picture.
3. Keep the **same file name**, including the extension. Commit.

The three files here are empty placeholders. Until a real picture takes their
place the site draws its own background instead, so nothing looks broken.

## What to upload

**hero.jpg** — the tall picture on the home page. Landscape, roughly 3:2
(for example 2400 × 1600). The heading sits over the left half, so leave that
side calm and keep the subject to the right.

**services.jpg** — a short, wide band. Roughly 3:1 (for example 2400 × 800);
a portrait photo loses its top and bottom to the crop. Same rule about the
left half, and the bottom edge fades into the page colour.

**logo.png** — square, at least 200 × 200. It is masked into a circle, so
keep the important part away from the corners. PNG with a transparent
background works; so does a solid one.

Keep each file under about 500 KB so the pages stay quick to open. Saving a
JPEG at around 80% quality gets almost any photo there with no visible
difference.
