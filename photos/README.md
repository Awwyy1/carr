# photos

Pictures that live in the repository rather than in the browser.

| file           | where it shows up                                   |
|----------------|-----------------------------------------------------|
| `services.jpg` | the wide band behind the heading on `services.html` |

Replace `services.jpg` with your own picture, keeping the **same file name**.
Nothing in the code needs to change.

A good picture for that band is wide rather than tall (roughly 3:1, for
example 2400 x 800), because the band is short and the sides of a portrait
photo get cropped away. Keep the file under about 500 KB so the page stays
quick to open — most photos survive being saved as JPEG at 80% quality with
no visible difference.

The subject is best kept to the right half of the frame: the heading sits on
the left, and the picture fades into the page colour along its bottom edge.
